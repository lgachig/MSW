# Music Sunday Worship

Aplicación Flutter para Music Sunday Worship.

## Verificación local

Desde este directorio (`musicsundayworship`), ejecuta:

```bash
flutter analyze
flutter test
```

La prueba de humo del arranque está en
`test/music_engine/smoke_test.dart` y puede ejecutarse directamente con:

```bash
flutter test test/music_engine/smoke_test.dart
```
